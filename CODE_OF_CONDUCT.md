# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussions about the work, and no harassment of any kind.
That includes how we talk about LM Studio and its developers. We document behaviour, we don't attack people.

Report problems by opening an issue marked "conduct" or by contacting the maintainer through GitHub.
The maintainer may remove comments, commits or contributors that break these rules.
